Reflexion

P1. Cual es la importancia de los sistemas de control de versiones como Git?

Los controles de versiones como Git son importantes porque permiten a los desarrolladores registrar y dar seguimiento a los cambios realizados en sus proyectos, mantener diferentes versiones de los archivos, colaborar con otros desarrolladores y recuperar versiones anteriores cuando se presentan errores, ademas de una excelente documentacion de cada proyecto

Ademas, el uso de ramas (branching) y la integracion de cambios (merging) permite desarrollar y probar nuevas funcionalidades sin afectar la version principal del proyecto. Esto facilita el trabajo en colaboracion, mejora la organizacion y reduce los riesgos durante el desarrollo de software sobre el control del codigo.
